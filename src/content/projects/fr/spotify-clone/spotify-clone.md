Une reconstruction au pixel près du lecteur web Spotify. Le design et les fonctionnalités étant fixés par l'original, tout l'exercice était de l'ingénierie : un vrai lecteur audio avec gestion du seek et de la file d'attente, OAuth sur l'API Spotify, cache serveur avec React Query, état client avec Redux Toolkit. Bien copier quelque chose reste un bon moyen de trouver où sont vraiment les difficultés.
